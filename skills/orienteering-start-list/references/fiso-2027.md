# Italy: FISO Start List Guidelines From 2027

Use this reference for Italian events (FISO — Federazione Italiana Sport Orientamento) held in 2027 or later, or whenever the organizer asks for the "nuove indicazioni FISO". These rules apply to Italy only; do not apply them to WRE/IOF or foreign events unless the organizer asks.

## What Changes

1. **Unchanged limits.** The total start window must stay contained, and the start load stays at 4-6 starters per minute, never more than 8.
2. **Different courses for all categories.** FISO asks course setters to give every category its own course. Courses arrive already made, so this only means there are more distinct courses and first controls to check. Keep checking first-control collisions per minute as usual.
3. **Larger intervals within the same category**, especially for masters:
   - Master categories (35+: M35, W35, M40 ... W75 and above): **minimum 2 minutes in sprint, 3 minutes in all other races** (middle, long, etc.).
   - If the number of entries and the window allow it, larger intervals are welcome (e.g. 4 minutes for small master classes in a middle/long race).
   - For non-master categories, FISO generally encourages wider gaps than before; keep the usual defaults (sprint 1, middle 2, long 2-3) unless the window clearly allows more, and ask the organizer.
4. **Randomization by strength groups** using a ranking (Coppa Italia, lista base/ranking list, or another list the organizer names):
   - Default: split the ranked category in **about three strength groups** (weakest/unranked first, strongest last) and shuffle within each group.
   - **Elite categories:** three groups are too coarse (the strongest athlete must not start 51st out of 75). Shuffle in **blocks of 5 or 10** from the end of the category instead, so the strongest runners stay in the final block.
   - Unranked athletes count as weakest and fall in the first group.
   - Report the seed and use a different seed per stage in multi-day events.

## Applying It With The Script

Set `"ruleset": "fiso-2027"` in the config. The script then:

- Detects master categories from the name (`M35`, `W 40`, `D45`, `H-50`, ...; age ≥ `master_min_age`, default 35). Override per category with `"master": true/false` for non-standard names.
- Raises master intervals to at least `master_min_interval_sprint` (default 2) in sprint and `master_min_interval` (default 3) otherwise, even if a lower `interval` is configured. The report says when an interval was raised.
- Tries wider intervals up to `master_max_interval` (masters) or `max_interval` (global or per category), and keeps the wider one only if the category still fits in `window_minutes` without pushing any minute over `max_load`. Categories are placed largest first, so wider intervals on early categories can use up room needed by later ones: check the report and lower the maximum if the window grows.
- For ranked categories (those with `rank_mode`, `invert_ranking`, `random_block` or `random_groups` in their config): uses `random_block` or `random_groups` if given; otherwise categories whose name contains "Elite" get blocks of `elite_random_block` (default 5), and all other ranked categories get `default_random_groups` (default 3) strength groups.
- Caps `peak_load` at 8 and keeps `max_load` at 6 unless configured lower.

Example:

```json
{
  "ruleset": "fiso-2027",
  "race_type": "middle",
  "first_start": "10:00:00",
  "window_minutes": 100,
  "max_load": 6,
  "master_max_interval": 4,
  "random_seed": 20270412,
  "stage": 1,
  "categories": {
    "M Elite": {"rank_mode": "points", "invert_ranking": true, "random_block": 5},
    "W Elite": {"rank_mode": "points", "invert_ranking": true, "random_block": 5},
    "M20": {"rank_mode": "points", "invert_ranking": true},
    "W20": {"rank_mode": "points", "invert_ranking": true}
  }
}
```

## Questions To Ask The Organizer

- Which ranking to use for seeding (Coppa Italia, lista base, other) and for which categories.
- Elite blocks of 5 or 10.
- Whether non-master categories should also get wider intervals, and the maximum interval for masters if the window allows it.
- Whether the window can grow if the master minimums make it too long, or whether extra start lanes are available.

## In Oribos

Oribos stores the interval per category (`<Intervallo>` on each `<categoria>`, see `read-file-og4`), so different intervals for masters and other categories can be carried over when the organizer enters the approved grid.
